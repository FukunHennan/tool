# 使用说明

1. 运行 `python server.py`，打开 http://127.0.0.1:8765/ 。
2. 旧浏览器首次连接空数据库时自动迁移行程；确认顶部显示连接或迁移成功。
3. 地图设置中填写高德 Web端 Key 和 securityJsCode，原浏览器已保存的配置继续可用。
4. 点击「添加地点」、列表中的地点或地图标记都会打开弹窗：填地址保存时自动定位，也可手动填坐标；编辑、删除、保存都在弹窗完成，悬停标记查看备注。
5. 「集合安排」同样以弹窗打开：只需设置集合点和北京时间；查询城市按集合点与同伴地址自动识别，出发时间直接按集合时间倒推。
6. 地点与集合安排存入后端。保存失败点击重试；冲突时先导出备份再刷新。
7. 导出行程用于备份，导入会显式替换地点；Key 不包含在导出中。

首次迁移前不要清理原浏览器存储。数据库说明与接口见 README.md。
