# ADR-0001：采用纯 Web 串口 MVP

- 状态：已接受
- 日期：2026-07-20

## 背景

项目需要构建一个部署在 EdgeOne 上的串口上位机。首要目标是尽快验证浏览器连接串口、数据收发及设备协议，而不是先建设账号、数据库或常驻云端服务。

## 决策

第一阶段使用 React + TypeScript 构建静态 Web 应用，通过 Web Serial API 访问用户电脑上的串口，并部署到 EdgeOne Makers。

实现必须通过 `DeviceTransport` 抽象隔离浏览器串口，使 Mock Transport 和未来的本地 Agent Transport 可以复用相同的 UI 与协议层。

串口日志默认只在用户本机处理，不自动上传云端。

## 结果

优势：

- 无需安装桌面程序。
- 无需首期后端基础设施。
- EdgeOne 提供 HTTPS 和静态资源分发。
- 可以快速验证设备协议和上位机交互。

代价：

- 浏览器兼容范围有限。
- 用户必须参与端口授权。
- 页面关闭后无法继续采集。
- 对某些驱动、CAN 和无人值守场景支持不足。

## 重新评估条件

出现以下任一需求时重新评估本决策：

- 开机自启或页面关闭后持续采集。
- 需要 CAN、复杂原生驱动或固件烧录工具。
- 需要远程控制现场设备。
- 目标浏览器不支持 Web Serial。
- 需要对串口权限进行企业级集中管理。
